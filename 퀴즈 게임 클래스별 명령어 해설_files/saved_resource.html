코드뜻이 프로그램에서의 역할
import jsonjson이라는 “도구상자”를 가져온다데이터를 파일에 글자로 저장·불러오기
import osos 도구상자를 가져온다파일이 있는지 확인
STATE_FILE = "state.json"변수 이름표에 파일명을 담는다저장 파일 이름을 한 곳에서 관리

1. Quiz 클래스 — “문제 카드 한 장”

전체 역할: 문제 1개의 정보를 담고, 그 문제로 할 수 있는 일(보여주기·채점·저장 변환)을 맡는다.

① 정보 담기 — __init__

코드뜻역할
class Quiz:“Quiz”라는 설계도(틀)를 만든다문제 카드의 틀
def __init__(self, ...)카드를 새로 만들 때 자동 실행되는 함수카드 만들 때 값 받기
self.question = question받은 값을 “내 것”으로 저장문제 문장 보관
self.choices = choices〃보기 4개 보관 (리스트)
self.answer = answer〃정답 번호(1~4) 보관
💡 def는 “기능 정의”, self는 “나 자신(이 카드)”입니다.

② 보여주기 — show()

코드뜻역할
print("\n문제:", self.question)화면에 글자 출력 (\n은 줄바꿈)문제 문장 표시
for i, choice in enumerate(self.choices, start=1):보기를 하나씩 꺼내며 번호를 1부터 붙여 반복보기에 1~4번 번호 붙이기
print(f"{i}. {choice}")글자 속에 변수 값을 끼워 출력 (f-문자열)“1. 야옹” 형태로 출력

③ 채점 — is_correct()

코드뜻역할
return user_answer == self.answer== 두 값이 같은지 비교해서 결과(True/False)를 돌려준다정답이면 True, 아니면 False

④ 저장용 변환 — to_dict() / from_dict()

코드뜻역할
return { "question": ..., ... }“이름: 값” 짝으로 된 딕셔너리를 돌려준다카드 → 저장 가능한 형태로 변환
@staticmethod카드 없이도 부를 수 있는 기능 표시저장된 데이터에서 카드를 “새로” 만들 때 사용
data["question"]딕셔너리에서 이름표로 값을 꺼낸다저장 내용 → 카드 복원
return Quiz(...)새 Quiz 카드를 만들어 돌려준다복원된 카드 반환

2. QuizGame 클래스 — “퀴즈쇼 진행자”

전체 역할: 카드 묶음(퀴즈 목록)과 최고 점수를 들고, 메뉴·입력·진행·저장을 총괄한다.

① 준비 — __init__, get_default_quizzes

코드뜻역할
self.quizzes = []빈 리스트(목록) 만들기퀴즈 카드를 모아둘 바구니
self.best_score = NoneNone은 “아직 없음”최고 점수 칸 비워두기
self.load_state()내 기능을 호출시작하자마자 저장 파일 불러오기
return [Quiz(...), ...]Quiz 5개를 목록으로 돌려준다기본 동물 퀴즈 5개 제공

② 저장·불러오기 — load_state, save_state

코드뜻역할
if not os.path.exists(STATE_FILE):파일이 “없으면”첫 실행 감지 → 기본 퀴즈 사용
try: ... except Exception:일단 시도, 오류 나면 except로 이동파일이 망가져도 프로그램 유지
with open(STATE_FILE, "r", encoding="utf-8") as file:파일을 열고, 블록이 끝나면 자동으로 닫는다 ("r"=읽기, "w"=쓰기)파일 안전하게 열기 (한글 깨짐 방지)
json.load(file)파일 내용을 파이썬 데이터로 읽는다저장 노트 읽기
data.get("quizzes", [])값을 꺼내되, 없으면 기본값(빈 목록)안전하게 꺼내기
self.quizzes.append(quiz)목록 끝에 하나 추가읽은 카드를 바구니에 담기
len(self.quizzes) == 0len은 개수 세기퀴즈가 하나도 없는지 확인
[quiz.to_dict() for quiz in self.quizzes]목록의 모든 카드를 변환해 새 목록 생성카드 전체를 저장 형태로
json.dump(data, file, ensure_ascii=False, indent=4)데이터를 파일에 글자로 적는다 (한글 유지, 들여쓰기 4칸)저장 노트에 기록

③ 입력 받기 — input_number, input_text

코드뜻역할
while True:조건 없이 계속 반복올바른 입력이 올 때까지 반복
input(message).strip()키보드 입력을 받고(input) 앞뒤 공백 제거(strip)사용자 입력 받기
if user_input == "":아무것도 안 쳤다면빈 입력 차단
continue이번 반복을 건너뛰고 처음으로“다시 입력하세요” 후 재요청
int(user_input)글자를 정수로 바꾼다 (실패하면 ValueError)숫자인지 검사
if number < min_number or number > max_number:범위보다 작거나(or) 크면1~4처럼 허용 범위 밖 차단
return number값을 돌려주고 반복 끝올바른 입력만 통과

④ 화면 — show_menu

코드뜻역할
print("=" * 30) 형태의 print글자를 화면에 출력메뉴 5개와 제목 표시

⑤ 퀴즈 풀기 — play_quiz, update_best_score

코드뜻역할
correct_count = 0맞힌 개수 변수를 0으로 시작점수 세기 준비
for quiz in self.quizzes:카드를 한 장씩 꺼내 반복문제를 차례로 출제
quiz.show()카드의 보여주기 기능 호출문제 출력
quiz.is_correct(user_answer)카드의 채점 기능 호출정답 여부 판단
correct_count += 1값에 1을 더한다정답 개수 증가
current_rate = correct_count / total_count나눗셈으로 정답률 계산이번 점수를 비율로 변환
if current_rate > best_rate:이번 정답률이 기존보다 높으면최고 기록 갱신 판단
self.best_score = {"correct": ..., "total": ...}딕셔너리로 기록 보관최고 점수 저장
return (값 없이)기능을 여기서 끝낸다첫 점수 저장 후 즉시 종료

⑥ 퀴즈 추가 / 목록 / 최고점수 — add_quiz, show_quiz_list, show_best_score

코드뜻역할
for i in range(1, 5):1, 2, 3, 4를 차례로 반복 (5는 제외)보기를 4번 입력받기
choices.append(choice)목록에 추가입력한 보기를 모으기
Quiz(question, choices, answer)새 카드를 만든다입력 내용으로 새 문제 생성
self.quizzes.append(new_quiz)바구니에 추가목록에 등록
enumerate(self.quizzes, start=1)번호를 붙여 하나씩 꺼내기[1], [2]… 번호 목록 출력
f"{rate:.1f}%"소수 첫째 자리까지 표시정답률 예: 80.0%

⑦ 전체 실행 — run

코드뜻역할
while True:무한 반복메뉴를 계속 다시 보여주기
if menu == 1: ... elif menu == 2: ...번호에 따라 갈림길 선택메뉴 번호와 기능 연결
break반복문을 즉시 탈출5번(종료) 선택 시 끝내기
except KeyboardInterrupt:Ctrl+C 눌림을 감지강제 종료 시 저장 후 안전 종료
except EOFError:입력이 끊긴 상황 감지〃

4. 명령어 한 줄 사전

명령어한 줄 뜻
class설계도(틀) 만들기
def기능(함수) 정의
self나 자신
return결과를 돌려주고 끝내기
print / input화면에 출력 / 키보드 입력 받기
if / elif / else만약 / 아니고 만약 / 그 외
for / while횟수·목록 기준 반복 / 조건 기준 반복
break / continue반복 탈출 / 이번 차례 건너뛰기
try / except시도 / 오류 시 대처
with open파일 열고 자동으로 닫기
append / len목록에 추가 / 개수 세기
==, >, <, and, or, not같다, 크다, 작다, 그리고, 또는, 아니다
