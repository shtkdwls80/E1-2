# 동물 상식 퀴즈 게임

## 1. 프로젝트 개요

이 프로젝트는 Python으로 만든 **콘솔 기반 퀴즈 게임**입니다.

프로그램을 실행하면 메뉴가 출력되고, 사용자는 메뉴 번호를 선택하여 다음 기능을 사용할 수 있습니다.

- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기
- 최고 점수 확인
- 프로그램 종료

퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장됩니다.
그래서 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지됩니다.

### 주요 특징

- 객체지향 방식으로 구현 (`Quiz` 클래스, `QuizGame` 클래스)
- 외부 라이브러리 없이 표준 라이브러리(`json`, `os`)만 사용
- 잘못된 입력(빈 입력, 문자, 범위를 벗어난 숫자)에 대한 예외 처리
- 저장 파일이 없거나 손상되어도 기본 퀴즈로 복구하여 계속 실행 가능
- `Ctrl+C`로 강제 종료해도 현재 데이터를 저장하고 종료

---

## 2. 퀴즈 주제와 선정 이유

### 퀴즈 주제

동물 상식 퀴즈

### 선정 이유

동물은 많은 사람들이 친숙하게 느끼는 주제입니다.
초등학생도 쉽게 이해할 수 있고, 재미있게 문제를 풀 수 있기 때문에 퀴즈 주제로 선택했습니다.

또한 강아지, 고양이, 기린, 펭귄, 토끼처럼 익숙한 동물을 사용하면 문제를 만들기도 쉽고, 게임을 플레이하는 사람도 부담 없이 즐길 수 있습니다.

### 기본 제공 퀴즈 (5문제)

| 번호 | 문제 | 정답 |
|------|------|------|
| 1 | 강아지는 보통 어떤 소리를 낼까요? | 2. 멍멍 |
| 2 | 고양이가 좋아하는 대표적인 장난감은 무엇일까요? | 2. 실뭉치 |
| 3 | 가장 키가 큰 동물은 무엇일까요? | 2. 기린 |
| 4 | 펭귄은 주로 어디에서 잘 살까요? | 1. 추운 곳 |
| 5 | 토끼가 좋아하는 음식으로 가장 잘 알려진 것은? | 1. 당근 |

## 3. 실행 방법

### 실행 환경

- Python 3.10 이상
- 외부 라이브러리 사용 없음 (표준 라이브러리만 사용)

### 실행 명령어

터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력합니다.

```bash
python E1-2.py
```

### 실행 화면 예시

```text
==============================
        동물 상식 퀴즈 게임
==============================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 최고 점수 확인
5. 종료
메뉴 번호를 선택하세요:
```

### 참고

- 처음 실행하면 `state.json`이 없으므로 "저장 파일이 없어 기본 퀴즈를 불러옵니다."라는 메시지와 함께 기본 퀴즈 5개로 `state.json`이 자동 생성됩니다.
- 실행 위치(현재 작업 폴더)에 `state.json`이 만들어지므로, 항상 같은 폴더에서 실행해야 저장된 데이터를 이어서 사용할 수 있습니다.

## 4. 기능 목록

### 1. 퀴즈 풀기
- 등록된 모든 퀴즈를 순서대로 출력하고, 정답 번호(1~4)를 입력받습니다.
- 문제마다 정답/오답 여부를 알려주며, 오답이면 정답 번호도 함께 보여줍니다.
- 모든 문제를 푼 뒤 "N개 정답 / 총 M문제" 형태로 결과를 출력합니다.
- 결과는 최고 점수와 비교하여, 정답률이 더 높을 때만 최고 점수를 갱신합니다.

### 2. 퀴즈 추가
- 문제, 선택지 4개, 정답 번호(1~4)를 차례로 입력받아 새 퀴즈를 등록합니다.
- 추가 즉시 `state.json`에 저장되어 다음 실행 때도 유지됩니다.

### 3. 퀴즈 목록 보기
- 등록된 모든 퀴즈의 문제, 선택지, 정답을 번호와 함께 출력합니다.

### 4. 최고 점수 확인
- 지금까지의 최고 기록(정답 수, 전체 문제 수, 정답률)을 보여줍니다.
- 아직 퀴즈를 푼 기록이 없으면 안내 메시지를 출력합니다.

### 5. 종료
- 현재 데이터를 저장하고 프로그램을 종료합니다.

### 입력 검증 및 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 아무것도 입력하지 않고 Enter | 안내 메시지 출력 후 다시 입력 |
| 숫자가 아닌 값 입력 | "숫자만 입력할 수 있습니다." 출력 후 다시 입력 |
| 허용 범위를 벗어난 숫자 입력 | 범위를 안내하고 다시 입력 |
| 퀴즈 추가 시 빈 문제/선택지 | "빈칸으로 둘 수 없습니다." 출력 후 다시 입력 |
| `state.json`이 없음 | 기본 퀴즈로 시작하고 파일 새로 생성 |
| `state.json`이 손상됨 | 손상 안내 후 기본 퀴즈로 초기화 |
| `Ctrl+C` 입력 | 현재 데이터를 저장하고 안전하게 종료 |
| 입력 스트림 종료(EOF) | 현재 데이터를 저장하고 안전하게 종료 |

## 5. 파일 구조

```text
프로젝트 폴더/
├── E1-2.py        # 게임 소스 코드 (실행 파일)
├── state.json     # 퀴즈 목록과 최고 점수 저장 파일 (실행 시 자동 생성)
└── Readme.md      # 프로젝트 설명 문서
```

### E1-2.py
게임의 전체 코드가 들어 있는 실행 파일입니다.

| 구성 요소 | 설명 |
|-----------|------|
| `Quiz` 클래스 | 퀴즈 1개를 표현. 문제 출력(`show`), 정답 확인(`is_correct`), JSON 변환(`to_dict`, `from_dict`) 담당 |
| `QuizGame` 클래스 | 게임 전체를 관리. 메뉴 출력, 퀴즈 풀기/추가/목록/최고 점수, 파일 저장·불러오기, 입력 검증 담당 |
| `STATE_FILE` | 저장 파일 이름을 정의한 상수 (`"state.json"`) |

### state.json
- 추가된 퀴즈와 최고 점수를 저장하는 데이터 파일입니다.
- 프로그램이 자동으로 생성하고 갱신하므로 직접 만들 필요가 없습니다.

## 6. 데이터 파일 설명 (state.json)

`state.json`은 게임의 상태를 저장하는 JSON 파일입니다.
프로그램을 종료했다가 다시 실행해도 퀴즈 목록과 최고 점수를 이어서 사용할 수 있도록 합니다.

### 저장되는 항목

| 키 | 타입 | 설명 |
|----|------|------|
| `quizzes` | 배열 | 등록된 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 내용 |
| `quizzes[].choices` | 문자열 배열 (4개) | 선택지 |
| `quizzes[].answer` | 정수 (1~4) | 정답 번호 |
| `best_score` | 객체 또는 `null` | 최고 점수. 기록이 없으면 `null` |
| `best_score.correct` | 정수 | 최고 기록 때 맞힌 문제 수 |
| `best_score.total` | 정수 | 최고 기록 때 전체 문제 수 |

### 예시

```json
{
    "quizzes": [
        {
            "question": "강아지는 보통 어떤 소리를 낼까요?",
            "choices": ["야옹", "멍멍", "꽥꽥", "음메"],
            "answer": 2
        }
    ],
    "best_score": {
        "correct": 4,
        "total": 5
    }
}
```

### 저장 및 불러오기 시점

| 시점 | 동작 |
|------|------|
| 프로그램 시작 | `state.json`을 읽어 퀴즈와 최고 점수를 불러옴 |
| 퀴즈 풀기 완료 | 최고 점수 갱신 여부를 판단한 뒤 저장 |
| 퀴즈 추가 | 새 퀴즈를 목록에 넣고 바로 저장 |
| 프로그램 종료 | 최종 상태를 저장 |

### 파일 문제 발생 시 동작

- **파일이 없는 경우**: 기본 퀴즈 5개로 시작하며, `state.json`을 새로 만듭니다.
- **파일이 손상된 경우** (JSON 형식 오류 등): 손상 안내 메시지를 출력하고 기본 퀴즈로 초기화합니다.
- **저장된 퀴즈가 0개인 경우**: 기본 퀴즈를 불러옵니다.
- 기본 상태로 되돌리고 싶다면 `state.json`을 삭제한 뒤 다시 실행하면 됩니다.
