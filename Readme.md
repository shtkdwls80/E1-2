# 동물 상식 퀴즈 게임

## 1. 프로젝트 개요

이 프로젝트는 Python으로 만든 콘솔 퀴즈 게임입니다.

프로그램을 실행하면 메뉴가 출력되고, 사용자는 메뉴 번호를 선택하여 다음 기능을 사용할 수 있습니다.

- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기
- 최고 점수 확인
- 프로그램 종료

퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장됩니다.  
그래서 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지됩니다.

---

## 2. 퀴즈 주제와 선정 이유

### 퀴즈 주제

동물 상식 퀴즈

### 선정 이유

동물은 많은 사람들이 친숙하게 느끼는 주제입니다.  
초등학생도 쉽게 이해할 수 있고, 재미있게 문제를 풀 수 있기 때문에 퀴즈 주제로 선택했습니다.

또한 강아지, 고양이, 기린, 펭귄, 토끼처럼 익숙한 동물을 사용하면 문제를 만들기도 쉽고, 게임을 플레이하는 사람도 부담 없이 즐길 수 있습니다.

## 3. 실행 방법

### 실행 환경

- Python 3.10 이상
- 외부 라이브러리 사용 없음
- 표준 라이브러리만 사용

```bash
python main.py
